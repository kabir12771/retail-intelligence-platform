\# Portfolio Review  

\# Retail Intelligence Platform



\## 1. Portfolio Summary



The Retail Intelligence Platform is a complete end-to-end analytics project for fashion retail and supply chain decision-making.



It demonstrates how raw operational retail files can be converted into:



\- Validated data

\- SQL Server staging tables

\- Dimensional warehouse facts and dimensions

\- Power BI-ready mart views

\- Executive dashboards

\- Forecast accuracy analysis

\- Stock optimization insights

\- Audit logs and run reports

\- GitHub portfolio documentation



This project is suitable for roles related to:



\- Data Analyst

\- BI Analyst

\- Power BI Developer

\- Inventory Analyst

\- Demand Planning Analyst

\- Merchandise Planning Analyst

\- Supply Chain Analyst

\- Junior Data Engineer
