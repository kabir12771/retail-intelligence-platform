\### Retail Intelligence Platform | Python, SQL Server, Power BI, GitHub



Built an end-to-end retail analytics platform that converts ERP-style Excel files into validated SQL Server warehouse tables and Power BI dashboards.



Key contributions:



\- Developed a Python ETL pipeline to ingest, validate, and load retail operational data.

\- Designed SQL Server staging, data warehouse, mart, and audit layers.

\- Implemented schema validation, data quality checks, post-load validation, and rejected-row error reports.

\- Created audit logging, technical logs, processed/rejected file movement, and Excel run summary reports.

\- Built Power BI dashboards for executive KPIs, sales performance, forecast accuracy, and stock optimization.

\- Developed DAX measures for sales, margin, forecast accuracy, WAPE, forecast bias, safety stock, reorder point, and inventory health.

\- Added GitHub Actions CI, release notes, QA checklist, user guide, and professional documentation.



Business areas covered:



\- Sales analytics

\- Inventory control

\- Purchase orders

\- Goods receipts

\- Transfers

\- Forecast accuracy

\- Stock optimization

\- Replenishment recommendations
