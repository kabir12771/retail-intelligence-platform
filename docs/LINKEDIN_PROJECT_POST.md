\# Retail Intelligence Platform



I am excited to share my latest portfolio project: Retail Intelligence Platform.



This is an end-to-end retail analytics solution built using Python, SQL Server, Power BI, Git, and GitHub.



The project simulates a real fashion retail data environment where business data comes from ERP-style Excel files, sales reports, inventory snapshots, purchase orders, goods receipts, transfers, forecast files, and stock optimization outputs.



The platform includes:



\- Python ETL pipeline

\- Excel file ingestion

\- Schema validation

\- Data quality checks

\- SQL Server staging tables

\- SQL Server data warehouse

\- Power BI-ready mart views

\- Audit logging

\- Rejected-row reports

\- Run summary reports

\- Power BI dashboards

\- Forecast accuracy analysis

\- Stock optimization analytics

\- GitHub Actions CI

\- Professional documentation



Power BI dashboards included:



\- Executive Overview

\- Sales Performance

\- Forecast Accuracy

\- Stock Optimization



Business areas covered:



\- Sales performance

\- Inventory control

\- Demand planning

\- Forecast accuracy

\- Replenishment planning

\- Stock optimization

\- Purchase order tracking

\- Goods receipt monitoring

\- Transfer operations



This project helped me strengthen my skills in Python ETL, SQL Server, Power BI, DAX, retail analytics, inventory control, forecasting metrics, GitHub documentation, and end-to-end business intelligence project delivery.
